## Base URL

```text
https://api.beelpoint.com
```

All endpoints are versioned under `/v1/api`.

## Authentication

Send your API Secret Key in the `authorization` header of every request.

```bash
curl https://api.beelpoint.com/v1/api/invoices/types \
  -H "authorization: YOUR_API_SECRET_KEY"
```

## Invoicing workflow

1. Retrieve reference data: invoice types, HSN codes and tax categories.
2. Generate an Invoice Reference Number (IRN) for the invoice.
3. Validate the invoice, or validate many at once with bulk validation.
4. Sign the invoice.
5. Confirm transmission using the IRN.
